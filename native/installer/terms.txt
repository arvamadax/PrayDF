#1. About PrayDF
PrayDF is a lightweight, open-source PDF viewer for Windows developed by arvamadax. The source code is at https://github.com/arvamadax/PrayDF.

#3. Privacy
- Documents are opened and rendered on your device. PrayDF does not upload documents, collect telemetry or ask for an account.
- PrayDF only downloads a file when you ask it to, that is when you open an http(s) or praydf: link to a PDF. The file is stored temporarily on your device so it can be opened.
- PrayDF checks every praydf: link before opening anything. Only http(s) URLs and absolute local PDF paths are accepted.

#4. Changes to your computer
This installer does the following:
- Copies praydf.exe, pdfium.dll, the licence text and the licences of third-party components to the install folder.
- Adds a PrayDF shortcut to the Start menu.
- Registers PrayDF with Windows as an app for .pdf files (Open with) and as the handler for praydf: links, and lists it under Settings > Apps > Default apps.
- An "Only for me" install writes only to folders and registry keys owned by your account (no administrator rights). A "For all users" install writes to Program Files and to the machine-wide registry, and asks for administrator permission.

PrayDF does not silently replace your default PDF app. Windows protects that choice, so you set PrayDF as the default yourself on the Default apps page. When you uninstall PrayDF from Settings > Apps, all of the files and registry entries above are removed too.

The licence text of each component is in the licenses subfolder of the install folder.
